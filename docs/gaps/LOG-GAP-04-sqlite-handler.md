# LOG-GAP-04: SQLite — неверный счётчик, ошибки в пакетном режиме, медленная запись

**Статус:** закрыт (07.10.2026)  ·  **Дата:** 2026-10-07  ·  **Находки:** F-07 … F-13  ·  **Задачи:** LOG-BL-03, LOG-BL-04

## Что нужно

Подробный журнал прохода в базе (по нему удобно искать запросами), который не замедляет тест в разы и не сыплет
ошибками в журнал терминала.

## Что есть (проба 07.10)

**Ошибки**
- `GetRecordCount()` возвращает 1 при любом числе записей (F-07).
- Пакетный режим: `PRAGMA synchronous = FULL` после каждого `COMMIT` + `BEGIN` выполняется уже внутри новой
  транзакции — ошибка 5601 и две строки в журнал на каждый пакет (F-08). Сама `PRAGMA` задаёт режим, который в SQLite
  и так действует по умолчанию.
- `SetAutoCommit(false)` на готовом обработчике не открывает транзакцию — первый `COMMIT` падает (F-09). Через
  фабрику другого способа включить пакет нет.

**Скорость**
- Автокоммит — 1,9 мс на запись; пакет по 100 — 63 мкс (F-10). Все готовые профили и `CreateCompositeLogger`
  по умолчанию работают в автокоммите. Профиль `DEBUG` (база от уровня `TRACE`) на 10 000 записей прохода — 19 секунд.
- Текст запроса собирается заново на каждую запись; четыре индекса.

**Прочее**
- Пять видов служебных строк в журнал терминала (F-11).
- Три столбца времени, целое время — через `int` (F-12).
- Одно имя базы на логгер — два экземпляра программы пишут в один файл (F-13, не проверено).

## Пробел

Счётчик неверен, пакетный режим работает с ошибками в журнале, а режим по умолчанию слишком медленный для тестера.

## Варианты

- Запись: подготовленный запрос (`DatabasePrepare` + `DatabaseBind`) один раз на обработчик; транзакция всегда,
  коммит по числу записей **и** по времени, а также в `Flush` и при закрытии.
- Надёжность против скорости: что теряется при аварийном завершении — последние N записей; для отладки падений —
  режим «коммит на каждую запись уровня ERROR и выше».
- Индексы — создавать по требованию (при чтении), не при записи.

## Предложение

Сначала ошибки (LOG-BL-03, без смены поведения), затем запись (LOG-BL-04, с проектом в `design/`).
