# Документы mql_logger

Документы библиотеки логирования лежат здесь, в её репозитории. Описание для пользователя — [`../README.md`](../README.md),
история изменений — [`../CHANGELOG.md`](../CHANGELOG.md).

| Папка | Что | Нумерация |
|---|---|---|
| [`review/`](review/) | Разборы кода: что нашли, чем подтверждено | по дате |
| [`gaps/`](gaps/README.md) | Пробелы: что нужно, а библиотека не даёт или даёт неверно | `LOG-GAP-NN` |
| [`backlog/`](backlog/README.md) | Задачи: что решено сделать | `LOG-BL-NN` |
| [`design/`](design/README.md) | Устройство как есть и проекты изменений до их реализации | `LOG-D-NN` |

Приставка `LOG-` — чтобы не путать с `GAP-NNN` и `BL-NNN` репозитория `mql`, куда библиотека подключена сабмодулем
`Include/Logger`.

**Порядок работы:** разбор → находки `F-NN` → пробел (что не так с точки зрения пользователя) → задача (что сделать);
задача, меняющая интерфейс или поведение, — сначала проект в `design/`.
