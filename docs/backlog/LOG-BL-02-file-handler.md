# LOG-BL-02: Файл — дозапись, ротация, кодировка, общий доступ

**Статус:** сделано (07.10.2026)  ·  **Приоритет:** P1
**Создано:** 2026-10-07  ·  **Источник:** LOG-GAP-03, F-01 … F-06  ·  **Зависит от:** LOG-BL-01
**Затрагивает:** `Handlers/FileHandler.mqh`, `Factory/LoggerFactory.mqh`; потребители — меняется кодировка файла

## Зачем

Дозапись стирает журнал прошлого запуска, ротация оставила 6 записей из 60.

## Что сделать

1. Открытие: `FILE_READ | FILE_WRITE | FILE_SHARE_READ | FILE_TXT`, переход в конец при дозаписи.
2. Кодировка: UTF-8 (`FILE_ANSI`, `CP_UTF8`) по умолчанию; UTF-16 — параметром. **Меняет формат файла** —
   записать в историю изменений.
3. Параметр «общая папка терминалов» (`FILE_COMMON`).
4. Ротация: имя архива с датой и временем или номером; предел числа архивов; имя резать по последней точке
   имени файла, не пути; размер считать с учётом буфера.
5. Сбой открытия или записи: одна строка в журнал терминала, повтор открытия не чаще раза в N секунд, предел
   буфера, счётчик потерянных записей (метод `DroppedCount()`).
6. `Handle` возвращает `false`, если запись не сохранена.

## Готово, когда

Тесты LOG-BL-01 на дозапись и ротацию проходят; журнал открывается в редакторе во время работы программы; при
недоступном файле в журнале терминала одна строка, а не строка на запись.

## Сделано (07.10.2026)

- `Handlers/FileHandler.mqh` переписан в части открытия, записи и ротации.
- Дозапись сохраняет файл (`FILE_READ | FILE_WRITE`), режим перезаписи обнуляет его один раз — при первом открытии.
- Кодировка — **UTF-8 без BOM** (было UTF-16); UTF-16 — пятым параметром конструктора. Файл открыт с
  `FILE_SHARE_READ`: журнал читается, пока программа работает. Общая папка терминалов — четвёртым параметром.
- Ротация: архивы `<имя>.<N><расширение>`, N растёт (больше — новее), занятые номера прошлых запусков
  пропускаются; `SetMaxArchives(n)` — хранить n последних; имя режется по последней точке имени файла; размер
  считается вместе с буфером. Не удалось переименовать — запись продолжается в прежний файл.
- Сбой открытия или записи — одна строка в журнал терминала на череду сбоев, повтор открытия раз в 5 с, предел
  буфера 1 МБ, `DroppedCount()`; `Handle` возвращает `false`, если запись не сохранена.
- Сброс буфера по интервалу — по `GetTickCount64()`, а не по времени тиков (часть F-19).
- Фабрика: `CreateFileHandler(filename, append, auto_flush, common, unicode)`.
- Тесты: 10 случаев файла (дозапись, ротация без потерь, нумерация архивов между запусками, предел архивов,
  кодировки, чтение во время работы, неоткрываемый файл) — все проходят, пометки F-01, F-02, F-04 сняты.
