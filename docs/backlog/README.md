# Бэклог

Задачи, которые решено сделать. Одна задача — один файл; сделанная остаётся со статусом «сделано» и коммитом.

**Имя файла:** `LOG-BL-NN-кратко-латиницей.md`.

**Шаблон:**

```markdown
# LOG-BL-NN: заголовок

**Статус:** новая | в работе | сделано (коммит) | отменена  ·  **Приоритет:** P1 | P2 | P3
**Создано:** ГГГГ-ММ-ДД  ·  **Источник:** LOG-GAP-… / F-…  ·  **Зависит от:** LOG-BL-…
**Затрагивает:** файлы; потребители (меняется ли их код или поведение)

## Зачем
## Что сделать
## Готово, когда
```

Приоритет: **P1** — теряются записи или неверный результат, либо без этого нельзя безопасно менять остальное;
**P2** — мешает пользоваться в тестере и на агентах; **P3** — улучшение.
