# LOG-BL-10: Журналы проходов тестера и агентов

**Статус:** новая  ·  **Приоритет:** P2
**Создано:** 2026-10-07  ·  **Источник:** LOG-GAP-05, F-39  ·  **Зависит от:** LOG-BL-05, LOG-BL-08
**Затрагивает:** новый обработчик, фабрика (профиль для тестера); в `mql` — советники, которые захотят этим
пользоваться (`OnTester`, `OnTesterPass`)

## Зачем

Журнал прохода на удалённом агенте остаётся на машине агента; проходы не различаются.

## Что сделать

1. Проверить (спайк): предел размера кадра `FrameAdd`, цена на проход, доходят ли кадры с удалённых агентов под
   Wine (в `mql` — пулы k99 и onec2).
2. Проект `design/LOG-D-…-tester-logs.md` по итогам: обработчик в память (счётчики по уровням + кольцевой буфер
   последних записей или записей от `WARN`), выдача кадром из `OnTester`, приём в `OnTesterPass` и запись в базу
   терминала с номером прохода и параметрами.
3. Минимум без проекта: счётчики записей по уровням у логгера (`Count(level)`), которые советник сам может
   отдать как показатель прохода.
4. Имена файлов для одиночного теста: добавка символа, периода и времени запуска — параметром фабрики.

## Готово, когда

После оптимизации в терминале видно, в каких проходах были записи `ERROR`, и по каждому такому проходу — их текст.
