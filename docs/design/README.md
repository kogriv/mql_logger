# Устройство и проекты

- [`architecture.md`](architecture.md) — как библиотека устроена **сейчас** (коммит `9a3c318`), без оценок. Оценки —
  в [`../review/`](../review/).
- Проекты изменений — по одному файлу `LOG-D-NN-кратко-латиницей.md`. Проект пишется до кода, когда задача меняет
  интерфейс, формат файла или таблицы, либо поведение, на которое опираются потребители.

**Шаблон проекта:**

```markdown
# LOG-D-NN: заголовок

**Статус:** черновик | принят (дата) | реализован (коммит) | отклонён  ·  **Задачи:** LOG-BL-…

## Задача            — что должно получиться и для кого
## Сейчас            — как устроено, со ссылками на код
## Решение           — интерфейс, форматы, поведение на границах
## Что рассмотрено и отвергнуто
## Совместимость     — что изменится для потребителей, перенос данных
## Проверка          — тесты и замеры, по которым судим
```
