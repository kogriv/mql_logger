# История изменений

Версия — `LOGGER_VERSION_STRING` в `Logger.mqh`. Первая цифра меняется, когда меняется поведение, на которое мог
опираться чужой код; вторая — новые возможности; третья — исправления.

## 2.0.0 — 2026-10-07

По разбору кода [`docs/review/2026-10-07-audit.md`](docs/review/2026-10-07-audit.md) (40 находок), задачи
`LOG-BL-01…13`.

### Меняет поведение

- **Файл журнала — UTF-8 без BOM** (был UTF-16). Прежнее — пятым параметром `CFileHandler` / `CreateFileHandler`.
- **Строка в журнале терминала** у обработчика без форматтера теперь та же, что в файле:
  `время [УРОВЕНЬ] имя: текст [файл:строка:функция] [Error: код]` (было `[время] УРОВЕНЬ: текст`).
- **Архивы ротации** называются `<имя>.<N><расширение>` (было `<имя>_<дата><расширение>`).
- **База:** индексы при записи не создаются; режим сброса на диск — `NORMAL` (был `FULL`); новые столбцы
  `time_local`, `elapsed_us`, `seq` (в старую таблицу добавляются при открытии).
- **Профили** ставят уровень логгера по наименьшему уровню обработчиков (`PERFORMANCE` — `WARN`); строка
  «initialized with … profile» — уровнем `INFO`.
- **Профили в тестере** очищают свою базу в начале каждого прохода (на графике — дописывают, как раньше).
- **Недопустимое имя логгера** даёт `NULL` (было — молча логгер `default`); в имени разрешена точка.
- **Повторное создание логгера** с тем же именем молча возвращает существующий.
- **Запись из обработчика в логгер** доставляется (раньше молча терялась); глубже 4 вложений — обрывается.
- **Логгер не закрывает обработчики** в деструкторе: их закрывает фабрика (или тот, кто создал их сам).
- Подробный формат: выдуманные миллисекунды убраны; цвета ANSI убраны (`SetUseColors` ничего не делает).
- Пустая запись `SLogRecord()` не отмечается временем — отметку ставят `CreateLogRecord()` и логгер.
- Удалены служебные строки в журнал терминала («Database closed», «Logger factory shutdown…» и др.).

### Исправлено

- Дозапись в файл стирала журнал прошлого запуска (F-01).
- Ротация теряла записи: архив одного дня перезаписывался (F-02); имя архива резалось по первой точке пути (F-03).
- `CSqliteHandler::GetRecordCount()` всегда возвращал 1 (F-07).
- Пакетный режим базы: ошибка 5601 на каждый пакет (F-08); `SetAutoCommit(false)` на открытой базе (F-09).
- Глобальная «блокировка» отбрасывала вложенные записи (F-14).
- Форматтеры меняли текст сообщения: схлопывали пробелы, подставляли поля внутри текста (F-20, F-21);
  `%logger%` в простом форматтере был пуст (F-22).
- Код ошибки, имя логгера и место вызова не попадали в журнал терминала (F-23).
- `LOGIF` не собирался (F-30); макросы могли взять чужую переменную `logger`, `LOGERROR` читал код ошибки после
  обращения к фабрике (F-31).
- `RemoveLogger` оставлял обработчики открытыми (F-27); `CreateCompositeLogger` мог настроить чужой обработчик
  базы (F-29); удаление объекта из-под реестра в `CreateProfileLogger` (F-28).
- Автосброс буферов зависел от тиков (F-19).

### Новое

- Макросы для указателя на логгер: `LOGTRACE_TO` … `LOGFATAL_TO`, `LOGERROR_CODE_TO`, `LOGFATAL_CODE_TO`.
- `CLoggerFactory::Default()`, `Exists()`, `CreateSubstringFilter()`; `CreateSqliteHandler(…, auto_commit,
  batch_size)`; `CreateFileHandler(…, common, unicode)`; `SLoggerConfig::db_auto_commit`, `db_batch_size`.
- `CLogger::DroppedCount()`, `GetHandler()`, `HasHandler()`.
- `CFileHandler`: `SetMaxArchives()`, `DroppedCount()`, `IsOpen()`, общая папка терминалов, чтение журнала во
  время работы.
- `CSqliteHandler`: `SetDurable()`, `FailedCount()`, `IsOpen()`, `CreateIndexes()`.
- Запись: `time_local`, `elapsed_us`, `sequence`; поля шаблона `%localtime%`, `%elapsed%`, `%seq%`.
- `CPatternFormatter` — общий разбор шаблона; `LogFormatDefault()`.
- `CSubstringFilter` (прежнее имя `CRegexFilter` оставлено как устаревшее).
- `CMemoryHandler` — последние строки в памяти; `CLogger::Count(level)`, `ResetCounts()`.
- `Tester/TesterLog.mqh`: `LogTesterSend()` и `CTesterLogCollector` — журналы проходов оптимизации в терминал
  кадрами (проверено с удалёнными агентами).
- `CreateProfileLogger(name, profile, db_file)`, `CLoggerFactory::RunFileName()`, `CSqliteHandler::Clear()`.
- Тесты `Tests/` (60 случаев; пример `QuickStart` выполняется в них), примеры `Examples/`, документы `docs/`.

### Удалено

- `Tests/LoggerTest.mq5`, `Tests/LogTest.mq5`, `LoggerTest.mq5` в корне (демонстрации без проверок), `.ex5`,
  файлы Replit; набросок архитектуры перенесён в `docs/design/history/`.
